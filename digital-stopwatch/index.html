How It Works

01 — Start

START sets the RUN state to 1. The 1 Hz clock is allowed to reach the counter.

02 — Count

Every enabled clock pulse increments seconds. Carries move through the ÷10 and ÷6 stages.

03 — Stop / Reset

STOP holds the current count. RESET clears the counter and returns RUN to 0.
